# 使用说明书

这份说明假设你完全没用过机械臂和 ROS。照着做就行，每一步只做一件事。

---

## 这是什么？

这是一个**机械臂抓东西的仿真程序**。

它不需要真的机械臂。它在电脑里画出一个虚拟的机械臂和一张桌子，桌上有一个红色小方块。程序会让虚拟的机械臂**把方块夹起来，搬到旁边，放下，再回到原位**。这样来回做 5 次。

就像电子游戏，只不过主角是一只机器手。

---

## 开始之前

你需要：

1. 一台 **Mac 电脑**
2. 一台 **Jetson**（一个小盒子电脑，程序装在它里面）
3. 一根 **USB 线**，把 Mac 和 Jetson 连起来
4. 如果想**看到画面**，Jetson 还要接一台**显示器**

**重要**：画面出现在 Jetson 接的那台显示器上，不会出现在 Mac 上。

---

## 第一步：把 Jetson 打开

1. 给 Jetson 插上电源
2. 用 USB 线连接 Mac 和 Jetson
3. **等一分钟**，让 Jetson 开机

怎么知道开好了？下一步如果能连上，就是开好了。

---

## 第二步：从 Mac 连到 Jetson

在 Mac 上打开「终端」这个程序，输入下面这行，然后按回车：

```
ssh nvidia@192.168.55.1
```

**成功的样子**：屏幕上出现 `nvidia@nvidia-desktop:~$`，说明你现在是在给 Jetson 下命令了。

**如果连不上**：跳到最后的「出问题了怎么办」第 1 条。

---

## 第三步：告诉程序去哪里找东西

复制下面这一整行，粘贴进去，按回车：

```
source /opt/ros/humble/setup.bash && source ~/mecharm_ws/install/setup.bash && source ~/Desktop/exp2_sim_ws/install/setup.bash
```

**这行是干嘛的？** 就像告诉电脑「工具箱在这三个抽屉里」。不说的话，电脑找不到程序。

**注意**：每次你新开一个终端窗口，都要重新输一次这行。

**成功的样子**：什么都不显示，直接回到那个 `$` 符号。没有报错就是对的。

---

## 第四步：让机械臂动起来

有两种玩法，选一种。

### 玩法 A：不看画面（推荐先用这个）

```
ros2 launch mecharm_grasp sim.launch.py gui:=false
```

屏幕会刷很多字。**这是正常的**，不是报错。

等大概 **1 分半钟**，看到这句话就是成功了：

```
任务完成：5 次抓取成功 5 次
```

### 玩法 B：看画面

先输这一行（**这行很重要，不输的话程序会直接崩掉**）：

```
export DISPLAY=:1
```

再输：

```
ros2 launch mecharm_grasp sim.launch.py
```

然后**去看 Jetson 接的那台显示器**，能看到机械臂在动。

⚠️ **注意**：开画面很吃资源，以前把 Jetson 卡死过一次。只是想确认程序能跑的话，用玩法 A。

---

## 第五步：看成绩单

程序跑完后，输入：

```
cat ~/mecharm_ws/grasp_logs/summary.txt
```

会看到：`任务完成：5 次抓取成功 5 次`

想看每一次的详细情况：

```
cat ~/mecharm_ws/grasp_logs/results.csv
```

每一行是一次抓取。第二个数字是 `1` 就代表这次成功了。

---

## 第六步：收尾

1. 如果程序还在跑，按住 **Control 键**再按 **C 键**，让它停下来
2. 然后输入下面这行，把没关干净的程序清掉：

```
for p in "ig[n] gazebo" "gras[p]_task" "robot_stat[e]_publisher" "parameter_bridg[e]" "spawne[r]"; do pkill -9 -f "$p"; done
```

**这行是干嘛的？** 有些程序关不干净会留在后台。不清掉的话，下次再跑会打架，出各种奇怪的错。

**每次跑完都要清一次。**

---

## 还有第二套抓取动作

这个程序里装了**两套**抓取动作，方块的位置不一样。

- **第一套**：方块放在偏右前方，机械臂转的角度小一些
- **第二套**：方块放在更靠前的位置，机械臂转的角度更大一些

上面第四步用的是第一套。想跑第二套，把命令里的 `sim` 换成 `sim2` 就行：

```
ros2 launch mecharm_grasp sim2.launch.py gui:=false
```

看第二套的成绩单，路径也不一样：

```
cat ~/grasp_logs2/summary.txt
```

⚠️ **两套不能同时跑**，会互相干扰。跑完一套，清理干净，再跑另一套。

---

## 出问题了怎么办

### 1. 连不上 Jetson，提示 `No route to host`

- 检查 USB 线两头有没有插紧
- 检查 Jetson 电源灯亮不亮
- 刚开机的话再等一分钟
- 还不行就拔掉 USB 线，重新插一次

### 2. 提示 `Package 'mecharm_grasp' not found`

你忘了做**第三步**。回去把那一长行重新输一遍。

### 3. 开了画面但显示器上什么都没有，程序还崩了

你忘了输 `export DISPLAY=:1`。这一行必须在启动命令**之前**输。

### 4. 程序卡住不动，或者报一堆红字

多半是上次没清理干净。按 Control+C 停掉，运行**第六步**的清理命令，然后重新来一遍。

### 5. 5 次里有失败的

先重跑一次看看。偶尔一次失败可能是物理引擎的随机误差。如果每次都失败，就是参数被改坏了。

---

## 想改点东西

改完必须**重新编译**，不然不生效。

### 改机械臂动作快慢、抓几次、夹爪松紧

改这个文件：

```
~/Desktop/exp2_sim_ws/src/mecharm_grasp/config/grasp.yaml
```

里面几个能改的数字：

| 名字 | 意思 |
|---|---|
| `cycles` | 抓几次 |
| `safe_height` | 搬运时抬多高（米） |
| `move_duration` | 每一段动作用几秒，数字越大越慢 |
| `gripper_close` | 夹爪合多紧 |

### 改方块放在哪里

要**同时改两个文件**，而且里面的位置数字必须一样，不然机械臂会抓空：

1. `config/grasp.yaml` 里的 `point_a`（去哪拿）和 `point_b`（放到哪）
2. `model/theWorld.sdf` 里方块的位置

⚠️ 机械臂手臂短，方块离底座**不能超过 15 厘米**，太远够不着。

### 改完之后必须做这一步

```
cd ~/Desktop/exp2_sim_ws && source /opt/ros/humble/setup.bash && source ~/mecharm_ws/install/setup.bash && colcon build --symlink-install
```

看到 `Summary: 1 package finished` 就是编译成功了。然后回到**第三步**重新开始。
